Supported Devices
-----------------

* AD7866

Overview
--------

The AD7866 is a dual 12-bit, 1 MSPS, 2-channel successive approximation ADC
with a serial interface. Each ADC has a 2-channel input multiplexer, and both
ADCs sample simultaneously.

The driver documentation will follow ``doc/driver_readme_template.rst`` from
no-OS once the driver is implemented.
